  • • ⚠️ 唔好自己即刻買貴酒店住先，打去 +852 2193 5875 問吓咩使費 claim 得
2. 跣親 / 扭傷
  • • 銀計劃海外醫療上限：HK$1,500,000
  • • 即刻做：
    • 1. 去診所 / 醫院，唔好自己捱
    • 2. 同醫生講清楚係「跌親 / 滑雪跌親」，要醫生寫明原因 + 診斷
    • 3. 拎齊：診斷書、藥單、收據、X光報告 (如有)
  • • ⚠️ 如果要入院 / 唔行得，打 +852 2193 5875，佢哋會幫手安排醫院 / 回港
3. 腸胃炎 / 屙嘔 / 發燒
  • • 同樣用醫療保障，唔好自己去藥房亂買藥了事
  • • 即刻做：
    • 1. 去診所睇，拎醫生紙寫明「腸胃炎 / Gastroenteritis」
    • 2. 拎藥單 + 收據
    • 3. 如果係食物中毒，記低食過邊間餐廳、幾點食
